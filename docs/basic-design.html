2. Navigation Structure

Shell を基点に、Gallery を背景として中位モーダル (Settings / WorldResolve / Group Drill Down) と上位モーダル (Photo Modal) を重ねる。
Bootstrap
  └─ Shell
      ├─ Gallery
      │   ├─ Group Drill Down (middle modal)
      │   └─ Photo Modal (top modal)
      ├─ Settings (middle modal)
      │   ├─ General
      │   ├─ Tag Master
      │   ├─ Template
      │   └─ Credits
      └─ World Resolve (middle modal)

3. Common Layout Rules

AreaDefinition
Headerフィルタ入口、ワールド検索、表示モード、ワールド別表示、複数選択、設定ボタンを配置する。
Main contentGallery を常設し、選択状態とフィルタ状態に応じて表示を更新する。
Middle modalSettings / WorldResolve / Group Drill Down を表示する。背景 Gallery は維持する。
Top modalPhoto Modal を表示する。中位モーダルが開いていても最上位に重ねる。
Feedbackスキャン、PDQ、WorldResolve 候補探索、サムネイル、保存失敗はトーストまたは画面内状態で表示する。

4. Screen Layouts

Gallery

写真一覧の標準表示。フィルタ、サムネイル要求、選択状態を扱い、日付順では月ナビゲーションを表示する。

┌ Header: filter | world search | view/group/select | settings ┐
├──────────────────────────────────────────────┬ Month navigation
│ Photo grid or masonry viewport               │ month list
│ [thumb][thumb][thumb][thumb]                 │
│ [thumb][thumb][thumb][thumb]                 │
├──────────────────────────────────────────────┴───────────────┤
└ Bulk actions: selected / clear / favorite / tag / copy      ┘

Photo Modal

大きな写真表示とワールド・タグ操作を 1 画面で扱う。

┌ Photo Modal ────────────────────────────── close ┐
├ Image preview                    ┬ World name     │
│ previous / next                  │ match source   │
│                                  ├ Tags           │
│ filename                         │                │
├──────────────────────────────────┴────────────────┤
└ Actions: favorite / post / world / Explorer      ┘

Settings

左ナビゲーションで設定カテゴリを切り替える。

┌ Settings modal ───────────────────────┐
│ Nav       │ Content                    │
│ General   │ folders / startup / post   │
│           │ theme / world resolve      │
│ Tags      │ tag list / add / delete    │
│ Template  │ template list / editor     │
│ Credits   │ creator / material credits │
└────────────────────────────────────────┘

World Resolve

ワールド名不明写真と候補ワールドを並べて確認する。

┌ World Resolve ────────────────────────┐
│ 候補探索の進捗                         │
│ target → predicted world / distance    │
│          matched photo / other choice  │
│ target → predicted world / distance    │
│ apply toggle / apply all / skip all    │
│ candidate picker                       │
│                    confirm / close      │
└────────────────────────────────────────┘

6. State and Feedback

StateDisplayTrigger
Scanning進捗、現在処理中ワールド、キャンセル状態PhotoScanner events
PDQ running解析件数、完了通知、World Resolve 利用可否PhashService events
