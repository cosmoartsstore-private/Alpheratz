2. Navigation and Layering

ShellはGalleryをmain contentとして維持し、検索条件、確認dialog、2段のmodal layerをその上に重ねる。開いていないlayerのcontentはclose animation後にversion guard付きで解放する。
Bootstrap
└─ ShellPage
   ├─ HeaderBar (44 px)
   ├─ ShellStage
   │  ├─ MainContentHost: Gallery
   │  ├─ ModalLayerHost: Settings | World Resolve | Group Drill Down
   │  ├─ TopModalLayerHost: Photo Modal
   │  ├─ ScanningOverlay
   │  └─ ToastHost
   ├─ FilterOverlay: fixed 612 px left panel
   └─ ConfirmOverlay: folder reset/change confirmation

Group Drill Downから写真を開く場合、Photo Modalは中位modalの上に表示する。SettingsとWorld Resolveを同じ中位layerで同時表示しない。Escは最上位の開いているviewから順に閉じる。

3. Common Layout Rules

Area / StateDefinition
Headerfilter入口、中央のworld search、view／group／multi-select操作、settings入口を置く。modalまたはfilter表示中は操作状態に合わせてdim・disableする。
Filter overlaypanelは幅612 pxで左側に固定し、表示時もparentを付け替えない。開閉はvisibilityと180 msのhorizontal slideで行う。
Middle modalSettings、World Resolve、Group Drill Down専用。Gallery stateとscroll位置を保持する。
Top modalPhoto Modal専用。中位modalからも起動できる。
Progressscan、gallery load、PDQ、World Resolve candidate searchは、実際の処理状態と件数をwave bar、overlay、status textで表示する。
Feedback局所validationは入力欄付近、操作結果と回復可能な失敗はtoast、破壊的folder操作はconfirm dialogを使う。
Responsive behavior狭いwindowではcontentをwrapまたはscrollし、長いworld/tag/file名でmodal幅を拡張しない。主要操作をviewport外へ固定しない。

World Resolve

初回解析中は件数付きoverlayを表示する。解析後はtargetとmatchを同じ行で比較し、適用予定状態を行単位で切り替える。

Candidate Picker / Preview

候補選択はWorld Resolve内のsubview。71%以上の候補をdistance順に示し、候補がない場合もmanual inputを常に利用できる。targetまたはmatch画像は上位preview overlayで拡大する。

│ [world name input] [use this name]       │
│ [candidate] world / 93%                  │
│ [candidate] world / 78%                  │
│ no candidate: guidance + manual input    │
└──────────────────────────────────────────┘

5. Interaction States

ContextEnabled StateBusy / Empty / Failure State
Gallery loadHeader controls are available when no blocking overlay is open.Top wave progress and loading veil。0件ならempty stateへ切り替える。
World search入力候補を最大5件表示し、Enterで検索を確定。入力だけでは再loadしない。候補0件でもplain textとして確定可能。
Multi-select選択件数とbulk actionsを下部barに表示。partial failure時は失敗写真だけを選択状態に残し、toastで再試行を案内。
PDQ analysis完了後にWorld Resolveを開ける。解析中はbuttonをdisableし、件数とprogressを同じ領域に表示。
World ResolveCanApplyの行だけtoggle・一括適用対象。candidateなしはmanual inputを案内。保存失敗は一部保存の可能性を明示。
Folder change利用者のconfirm後に実行。scan、post-scan、thumbnail完了を待つ。cleanup失敗時は新しいscanを開始しない。
Postactive templateがある場合だけ実行。clipboard、browser、optional world pageを段階別messageで通知。

6. Visual and Accessibility Contract

RuleCurrent Contract
ThemeLight / DarkともXAML theme resourcesを正本とし、hard-coded色は局所的な意味色に限定する。
Hierarchypage title、section title、body、hintの順を保ち、同じ領域へ複数の強いaccentを重ねない。
Status色だけに依存せず、text、icon、enabled state、progress countを併用する。
KeyboardEscでoverlayを閉じ、Photo Modalは左右keyで移動し、world searchとtag inputはEnter操作を持つ。
Automationicon-only button、preview、previous/next、folder操作にはautomation nameまたはhelp textを与える。
Long contentworld、tag、filenameはwrapまたはellipsisを使い、screenやmodalの幅を押し広げない。
Virtualizationreused photo cardはLoadedだけでなくDataContextChangedでもfavorite等のvisual stateを同期する。
