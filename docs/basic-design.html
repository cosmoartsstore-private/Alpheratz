2. Navigation Structure

Shell を基点に、Gallery を背景として中位モーダル (Settings / WorldResolve / Group Drill Down) と上位モーダル (Photo Modal) を重ねる。
Bootstrap
  └─ Shell
      ├─ Gallery
      │   ├─ Group Drill Down (middle modal)
      │   └─ Photo Modal (top modal)
      ├─ Settings (middle modal)
      │   ├─ General
      │   ├─ Tag Master
      │   ├─ Template
      │   └─ Credits / Integrations
      └─ World Resolve (middle modal)

3. Common Layout Rules

AreaDefinition
Headerロゴ、検索・フィルタ入口、表示モード、設定ボタン、進捗表示を配置する。
Main contentGallery を常設し、選択状態とフィルタ状態に応じて表示を更新する。
Middle modalSettings / WorldResolve / Group Drill Down を表示する。背景 Gallery は維持する。
Top modalPhoto Modal を表示する。中位モーダルが開いていても最上位に重ねる。
Feedbackスキャン、PDQ、WorldResolve 候補探索、サムネイル、保存失敗はトーストまたは画面内状態で表示する。

4. Screen Layouts

Gallery

写真一覧の標準表示。フィルタ、月別グループ、サムネイル要求、選択状態を扱う。

┌ Header: logo / search / filter / view / settings ┐
├ Toolbar: scan status / PDQ progress / actions    ┤
├ Filter summary / month navigation                ┤
├──────────────────────────────────────────────────┤
│ Photo grid or masonry viewport                   │
│ [thumb][thumb][thumb][thumb]                     │
│ [thumb][thumb][thumb][thumb]                     │
└ Status: count / selected / warnings              ┘

Photo Modal

写真詳細、タグ、類似候補を 1 画面で扱う。

┌ Modal header: filename / close ┐
├ Image preview                  ┬ Metadata
│                                │ world / timestamp / slot
│                                │ favorite / missing
├ Tags                           │
├ Similar photos                 │
└ Actions: save / open / copy / tweet

Settings

左ナビゲーションで設定カテゴリを切り替える。

┌ Settings modal ───────────────────────┐
│ Nav       │ Content                    │
│ General   │ folder / theme / startup   │
│ Tags      │ tag list / add / delete    │
│ Template  │ template list / editor     │
│ Credits   │ StellaRecord registration  │
└────────────────────────────────────────┘

World Resolve

世界不明写真と候補ワールドを並べて確認する。

┌ World Resolve ────────────────────────┐
│ 候補探索の進捗                         │
│ Unknown photo list │ Candidate panel   │
│ [photo]            │ world candidates  │
│ [photo]            │ PDQ distance      │
│ [photo]            │ apply / skip      │
└────────────────────────────────────────┘
